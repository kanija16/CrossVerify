# Changes made for the public release / paper revision

No reported number changed. All edits either add missing files or make existing scripts run
outside the original authors' machines. Every script below was re-run after editing and
reproduces the previously saved outputs exactly.

## Added

| File | Purpose |
|---|---|
| `generator/` | Dataset generator code, tests, README, `BUILD.md`, QA log `final_check.log` (zbar decoder warnings stripped) |
| `src/m3_crossmodal/fusion/generate_m3_oof.py` | Previously missing script for M3 out-of-fold predictions. Reproduces all 7,700 values exactly |
| `outputs/fusion/oof/train_oof_predictions.csv` | Regenerated by the script above (was referenced but not committed). Values identical to `m3_probability_oof` in `corrected_fusion_oof.csv` |
| `src/evaluation/bootstrap_ci.py`, `outputs/fusion/test_bootstrap_ci.json` | Bootstrap CIs; reproduce every CI in the paper exactly (CNN, M3, fusion) |
| `src/analysis/crossverify_audit.py`, `outputs/revision_analysis/crossverify_audit_output.txt` | Revision analyses (McNemar, prevalence, read failures, simple fusion baselines, Brier) |
| `src/analysis/qr_decoder_comparison.py` | OpenCV (M3) vs pyzbar (generator) QR readability on the images |
| `src/baseline/train_cnn_e2e.py` | End-to-end image-only CNN baseline on `final_label`. Run with a 15-epoch and a 30-epoch budget (`--epochs 30`); outputs in `outputs/baselines/cnn_e2e*/` |
| `outputs/baselines/cnn_e2e/`, `outputs/baselines/cnn_e2e_ep30/` | End-to-end baseline predictions, metrics and training logs (15- and 30-epoch runs; the 30-epoch run is the paper's headline) |
| `src/analysis/e2e_per_type.py` | Per-mechanism analysis of the end-to-end baseline (flag rates, AUC vs. genuine, Fisher, Mann-Whitney) |
| `LICENSE` | MIT License for the code |
| `src/m3_crossmodal/model_io.py` | Loads the scikit-learn 1.6.1 M3 models under newer scikit-learn (patch from pre-test gate 2) |
| `requirements/*.txt` | Pinned environments (generator versions read from its virtualenv; others from the paper) |
| `README.md` | Rewritten: layout, dataset, reproduction steps, notes |

## Known gaps (documented in README)

- CNN weights (`models/cnn/best_model.pt`, `models/cnn_oof/fold_*`) were not retained.
- `src/baseline/verify_cnn_oof.py` check J (fold checkpoints on disk) fails for that reason; all other checks pass.
- `generator/BUILD.md`: the build command is confirmed (`--n_records 500 --seed 42`, identities verified by regeneration). The script that produced the family-stratified `data/splits/` is not included (the current `make_splits.py` pools families and gives a different assignment); the released split files are the reference.
